# InstaGoose Profile System

A Python-based social media profile system that demonstrates object-oriented programming and interactive user input.

## Overview

This project simulates a simple social media profile system called InstaGoose. Users can create profiles, view existing profiles, and search for users by username.

## Features

- Create user profiles
- Store usernames, ages, bios, and follower counts
- Search for profiles by username
- View formatted profile information
- Interactive command-line menu

## Concepts Used

- Python
- Object-oriented programming
- Classes and objects
- Constructors
- Instance variables
- Getter and setter methods
- Lists
- Functions
- Loops and conditionals
- User input
